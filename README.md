Лабораторная работа №5. Хэширование

Студент: Дионг Тьерно Адама
Вариант: 9

Задача: реализовать поиск, вставку, удаление, печать хэш-таблицы и рехэширование при росте данных.

Параметр	Значение
Ключ	СНИЛС
Хэш-функция	функция свёртки (слияния)
Разрешение коллизий	бинарные деревья

Все структуры данных (таблица, деревья, список) написаны вручную, готовые коллекции Java не используются.

Структура

Файл	Назначение
src/MyList.java	собственный динамический список
src/Entry.java	элемент таблицы: СНИЛС и ФИО
src/Snils.java	проверка и форматирование СНИЛС
src/HashFunction.java	хэш-функция свёртки
src/TreeBucket.java	бинарное дерево поиска в ячейке таблицы
src/HashTable.java	таблица: вставка, поиск, удаление, печать, рехэширование
src/Main.java	меню и ввод данных
